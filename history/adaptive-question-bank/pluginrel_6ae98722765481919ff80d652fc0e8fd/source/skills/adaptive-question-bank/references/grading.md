# Grading protocol (v2.2.0)

1. **Single choice**: compare stable option ID to correct ID; exact 0 or 1. Avoid revealing key until answer submitted.
2. **Numeric**: parse finite numeric value; normalize units only when conversion is explicitly supported; check absolute/relative tolerance. Report expected result, formula, and relevant units after grading. Reject NaN/ambiguous units; seek clarification when reasonable.
3. **Sequence**: compare ordered values with expected sequence. For partial credit, award only if a question-specific rubric defines it; do not silently invent partial credit.
4. **Short answer**: construct a criterion-based rubric before grading; grade semantic content, not wording. Example for why binary search is efficient: interval-halving 2 points, sorted-data prerequisite 1 point, logarithmic vs linear complexity 1 point. Normalize score by maxScore.
5. Return `score`, `maxScore`, `isCorrect` (based on full correctness, not partial credit), `feedback`, `detectedMisconceptions[]`, `needsReview`. Use `needsReview=true` when ambiguous, conflicting, or the grading evidence is low-confidence; do not treat tentative diagnoses as confirmed.
6. Confidence is optional and must be captured before correctness feedback or answer disclosure. It never changes the score. Store a later estimate separately; do not overwrite the pre-feedback value or convert verbal uncertainty to a number.
7. Record `supportCondition` from actual events: `unassisted`, `scaffolded`, `solution_exposed`, or `unknown`. Hints reduce independence; an answer revealed before completion makes the continuation `solution_exposed`. Keep first-attempt results and support events. Never count assisted success as unassisted mastery evidence.
8. In Quiz Mode, for wrong or stuck answers, request reasoning when useful and classify provisionally as `conceptual`, `procedural`, `arithmetic`, `strategic`, `mixed`, or `unclear`. Preserve uncertainty and alternative explanations. One clear arithmetic slip needs a brief self-check, not an extended interview. Blank/`I don't know` is not evidence of an arithmetic or procedural path.
9. For wrong answers in Quiz Mode, give concise targeted feedback and optionally a small hint, then offer a fresh related question. For correct answers, explain the governing principle briefly. Gate transfer according to `evidence-and-transfer.md`; do not run it automatically.
10. In Exam Mode, withhold all correctness feedback, diagnosis and answer disclosure until final submission. Freeze the original score and attempts before post-exam work; later retries cannot alter them.
11. Do not fabricate execution results or claim to have run code/calculations without actually doing so. Check arithmetic independently when tools are available.
