# Critical question bank
Select and specialize questions; do not mechanically ask all of them.

| Stage | Pattern | Starting question |
|---|---|---|
| Orientation | Definition | What precisely is it, and what is it not? |
| Orientation | Context | Which broader system or discipline contains it? |
| Orientation | Decomposition | What components are essential? |
| Motivation | Purpose | Which problem is it designed to solve, for whom? |
| Motivation | Causality | What pressures or shortcomings led to it? |
| Motivation | Evolution | What preceded it and what changed? |
| Mechanism | Process | How does it operate step by step? |
| Mechanism | Assumptions | What conditions must hold for its claims to be valid? |
| Mechanism | Relationships | How do the parts influence one another? |
| Relationships | Comparison | What is the strongest relevant alternative? |
| Relationships | Trade-offs | What is gained and sacrificed relative to that alternative? |
| Relationships | Connections | What existing concept offers a useful analogy, and where does it break? |
| Critical evaluation | Evidence | What evidence directly supports the central claim? |
| Critical evaluation | Counterexample | Under what plausible condition does the claim fail? |
| Critical evaluation | Limitations | What cannot it do, or when does it degrade? |
| Critical evaluation | Alternative explanation | Could a confounder explain the reported result? |
| Application | Use cases | In which concrete scenarios does it create value? |
| Application | Experiment | What minimal test could validate the important assumption? |
| Application | Prediction | What changes if an important parameter changes? |
| Application | Optimization | What improvement is most promising and at what cost? |
| Reflection | Knowledge gaps | Which part of the explanation remains unclear? |
| Reflection | Verification | What evidence or example would verify my understanding? |
| Reflection | Prioritization | Which unanswered question would change my decision most? |
| Reflection | Synthesis | Can I explain the mechanism and limitations without jargon? |

## Adaptive branching examples
- 'Faster' -> faster on which benchmark, hardware, dataset, and baseline?
- 'More secure' -> against which threat model, and supported by what audit or design property?
- 'Easy to use' -> for which user/task and compared with what alternative?
- 'Novel idea' -> which assumption is riskiest, and how can it be cheaply tested?
- 'I do not understand' -> isolate missing prerequisite and explain with one concrete example.
