# Assessment blueprint

Define a table of topic/objective IDs, planned item counts, question types, cognitive targets, and estimated difficulty. Honor explicit requirements. If user requests balanced coverage across N topics, allocate floor(Q/N) to each and distribute remaining slots fairly among eligible topics. Do not silently exclude topics lacking enough source-backed material; report the gap. Sample multiple objectives within each topic where feasible. Treat difficulty labels as provisional until calibrated from student data. Ensure the blueprint matches the actual generated item set.
