# Analyze it
Read the actual supplied lecture material; never infer missing pages or content. Extract coherent topic units with observable objectives, prerequisites, and page references. Preserve course and lecture identifiers and stable existing topic IDs when matched. Classify each record as new, unchanged, changed, duplicate, split or merged. Produce a human-readable diff and machine-readable proposal. Require explicit approval before initial import and every material change. Submit approved proposal to Update it only if a real tool is available; otherwise export JSON and state that no synchronization occurred. Never directly assign mastery scores. Cite source pages and flag uncertain coverage.
