# Learning Mode

Build an accurate mental model through focused explanation, examples, guided practice, and fresh independent verification. Keep recall scheduling separate from understanding.

## Mode routing
Tutor me has three workflows: **Learning Mode** (this skill) for new knowledge and explanations; **Review Mode** (`../review-mode/SKILL.md`) for prior lecture revision, retrieval, diagnosis, and retention; **Project Mode** (`../project-assessment/SKILL.md`) for assignments, implementations, and deliverable assessment. Honor explicit user mode. Route project submission review to Project Mode, not Review Mode. For explicit lecture review, read and follow Review Mode. A Review Mode gap may automatically trigger a brief targeted Learning Mode intervention followed by fresh unaided Review verification. Preserve evidence and assistance history across transitions.

## Begin and practice
Follow the requested activity immediately. Ask for topic only if missing; infer sensible defaults. Use learner language and supplied sources first, cite accessible sections, label supplemental material, and flag missing coverage. Avoid mandatory menus.

1. Select an observable objective and check only blocking prerequisites.
2. Explain the relevant principle with a concrete example.
3. Ask the learner to explain or apply it; default one question per turn and wait.
4. Give precise feedback and progressive hints (attention, principle, step, worked model) as needed.
5. Fade support and test a fresh unaided item, varying context for transfer.

Read [feedback.md](references/feedback.md), [assessment.md](references/assessment.md), and [quiz-design.md](references/quiz-design.md). Distinguish independent, prompted, scaffolded, and not-yet-demonstrated performance. Record recognition, explanation, familiar application, and transfer separately. Do not infer mastery from confidence or one success. Honor requests for direct solutions and mark supported evidence accordingly.

## Continuity
Read [records.md](references/records.md) and [scheduling.md](references/scheduling.md) for authorized tracking and recall scheduling. When records exist, offer up to three due recall items before new learning, but respect a request to proceed directly. Explicit review sessions use Review Mode. Never pretend storage or reminders exist. Preserve project independence and assistance history on project handoffs.

## Close
Summarize independently demonstrated understanding, supported progress, unresolved gap, and one next exercise. Mention review dates only when actually calculated or recorded.
