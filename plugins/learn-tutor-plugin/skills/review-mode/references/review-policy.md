# Adaptive review selection and handoff

Use a transparent priority hierarchy, not fabricated numerical weights:
1. Due recall items and repeatedly failed concepts.
2. Concepts previously correct only with prompting/scaffolding and unassessed objectives.
3. Concepts with uncertain or contradictory reasoning evidence.
4. Confusable methods or concepts where strategy discrimination has not been demonstrated.
5. Recently independently demonstrated concepts when due or needed for balanced coverage.

Balance priorities against objective coverage and user-specified scope. Rotate among objectives; do not spend the whole session on one gap unless explicitly requested. Choose the next item to resolve a meaningful uncertainty. Vary cognitive evidence (recall, explanation, familiar application, strategy discrimination, transfer) and increase difficulty after repeated independent success; keep difficulty stable when evidence is mixed. No hints on scored independent attempts.

## Interleaved discrimination
After the learner has enough foundation in two or more related approaches, deliberately mix them when choosing the appropriate approach is itself part of the objective. Ask the learner to identify or justify the method rather than announcing it in the stem. Use meaningful contrasts, not random topic switching. Do not interleave untaught material or turn missing prerequisites into guessing. If the learner can execute each method but repeatedly selects the wrong one, treat strategy selection as the bottleneck and target it directly.

Immediate response policy: report whether the answer meets the criterion, name the observed issue, and ask one diagnostic question if the cause is uncertain. 'I don't know' indicates not-yet-demonstrated knowledge, not a guessed misconception. A plausible typo with correct method merits a fresh independent check, not automatic reteaching. A wrong method or repeated conceptual failure merits targeted relearning. A correct result with invalid reasoning requires an explanation/verification check. Do not alter the original attempt score after later clarification; record new evidence separately.

Automatic Learning handoff: state the gap briefly, teach the minimum missing principle, run one supported practice attempt, then return to a novel independent Review item. Preserve mode context, scope, attempt history, and requested session budget. If a project is active, preserve project-assistance accounting; never treat a supported project result as independent.
